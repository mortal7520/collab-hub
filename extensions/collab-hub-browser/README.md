# CollabHub Browser Chat-Box Companion (Zero-Dependency MV3)

Anchors an always-on **Shadow DOM** HUD capsule directly beside the chat composer on:
`claude.ai`, `chatgpt.com`, `gemini.google.com`, `muse.ai`, `chat.deepseek.com`, `grok.com`, and `perplexity.ai`.

## 10-Second Install (Unpacked)

1. Open `chrome://extensions` (or `edge://extensions`).
2. Enable **Developer mode**.
3. Click **Load unpacked** and select this `extensions/collab-hub-browser` directory.

Strictly privacy-safe: communicates only with local `http://127.0.0.1:5290` read-only endpoints and never accesses browser cookies, tokens, or conversation history unless you click **Route Draft** / **Insert into Chat**.
